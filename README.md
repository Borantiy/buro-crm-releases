# Бюро CRM

Настольная CRM для кадастровых работ, Windows x64.

## Скачать

**[Скачать установщик последней версии](https://github.com/Borantiy/buro-crm-releases/releases/latest)**

Выберите файл `Buro-CRM-Setup-<версия>.exe`. Устанавливать Node.js и открывать браузер для работы не нужно.

После установки создайте два аккаунта. Данные и документы сохраняются локально на компьютере.

## Обновления

В приложении откройте свой аккаунт и раздел «Обновления приложения». Проверка выполняется также при запуске. Новая версия скачивается по нажатию кнопки и устанавливается после выбора «Установить и перезапустить».

Для обновлений не нужен аккаунт GitHub. База и вложения находятся вне папки программы и сохраняются при обновлении.

Portable-версия `Buro-CRM-<версия>-Windows.exe` запускается без установки, но обновляется вручную скачиванием нового EXE. Для обновлений из приложения используйте установщик Setup.

## Что внутри

Сделки, клиенты, задачи, календарь, выписки с вложениями, корреспонденция, внутренние обсуждения и финансовый учёт.

Синхронизация между компьютерами и облачное хранение пока не подключены. Установки на разных компьютерах используют отдельные базы.

## Данные

Рабочая база и вложения: `%APPDATA%\BuroCRM\work`.

В аккаунте владельца есть создание резервной копии. Данные клиентов не загружаются в этот репозиторий.

В этом открытом репозитории размещаются только сборки и сведения о версиях. Репозиторий разработки остаётся закрытым.
